# Roteiro de validação funcional

Este roteiro tem como objetivo apoiar a validação do MVP Gestão de Toner.

## Cenários de teste

### Consulta de solicitações
- abrir a aplicação;
- verificar a exibição dos pedidos demonstrativos;
- confirmar a separação por status.

### Pesquisa
- utilizar o campo de busca;
- pesquisar por chamado, solicitante ou equipamento;
- verificar se a lista é filtrada corretamente.

### Nova solicitação
- acessar Solicitar Toner;
- selecionar uma impressora;
- informar contador e solicitante;
- confirmar o registro da solicitação.

### Consulta de contador
- acessar Consulta Contador;
- verificar a apresentação dos valores demonstrativos.

### Estoque
- acessar Configuração > Estoque;
- verificar os toners cadastrados;
- validar quantidade e estoque mínimo.

### Alteração de status
- selecionar uma solicitação;
- alterar os dados necessários;
- confirmar que o novo status é apresentado na tela principal.

## Resultado esperado

As funcionalidades devem operar de forma independente dos dados e serviços utilizados pela versão de produção.
