# Checklist antes de publicar no GitHub

- [ ] Confirmar que o repositório será público somente com esta versão acadêmica.
- [ ] Não copiar `dados/email.properties` da versão em uso.
- [ ] Não copiar `pedidos.db`, `estoque.db`, logs ou arquivos de produção.
- [ ] Executar `git status` e revisar todos os arquivos antes do primeiro commit.
- [ ] Verificar que não existem IPs internos, e-mails corporativos, tokens ou URLs reais.
- [ ] Usar um README claro e manter os commits com mensagens descritivas.
